Maps generated from QMK's keyboard definitions (https://github.com/qmk/qmk_firmware,
GPL-2.0-or-later) by `scripts/maps.sh`: each key's LED in the firmware's
rgb_matrix order, for keyboards OpenRGB lights without giving their key
matrix. `boards.json` lists them, with the names a keyboard might report.
They haven't been checked on the boards themselves; `keybars find` makes a
map by hand when one is wrong.
